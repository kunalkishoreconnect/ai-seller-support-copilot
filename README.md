# Case 1: AI Seller Support Copilot

A portfolio prototype demonstrating AI product thinking for an e-commerce shipping platform.

## Contents
- `knowledge_base.csv`: 46 hypothetical FAQ entries.
- `evaluation_questions.csv`: 49 test questions with expected actions.
- `app.py`: Streamlit chat interface.
- `copilot_logic.py`: retrieval, confidence, and escalation logic.
- `PRD_AI_Seller_Support_Copilot.md`: product requirements.
- `evaluation_report_template.md`: evaluation framework.

## Run locally
```bash
pip install streamlit pandas
streamlit run app.py
```

## Important disclaimer
This prototype uses hypothetical policies and does not represent Shiprocket’s actual internal policies, data, or systems.
